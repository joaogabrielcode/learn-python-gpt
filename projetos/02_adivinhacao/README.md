# Jogo de adivinhação

## Objetivo

Construir um jogo no qual a pessoa tenta descobrir um número secreto em tentativas limitadas.

## Requisitos

- Gerar ou definir o número secreto dentro de uma faixa.
- Informar se o palpite é maior ou menor.
- Contar e limitar tentativas.
- Validar palpites fora da faixa.
- Oferecer uma nova partida.

## Funcionalidades

- Gerar ou definir o número secreto dentro de uma faixa.
- Informar se o palpite é maior ou menor.
- Contar e limitar tentativas.
- Validar palpites fora da faixa.
- Oferecer uma nova partida.

## Conhecimentos necessários

- Módulos 01 a 06.
- Condicionais, while, for, contadores e biblioteca random.

## Exemplo de uso

```text
Palpite: 40
O número secreto é maior.
Palpite: 57
Você acertou em 2 tentativas!
```

O exemplo ilustra o comportamento esperado, não a implementação.

## Funcionalidades extras opcionais

- Níveis de dificuldade.
- Recorde de menor número de tentativas.
- Modo para dois jogadores.
