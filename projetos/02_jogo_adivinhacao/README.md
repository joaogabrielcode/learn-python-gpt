# Jogo de adivinhação

## Objetivo

Construir um jogo de terminal com número secreto, feedback, tentativas e partidas repetidas.

## Pré-requisito recomendado

Após concluir o Módulo 03.

## Funcionalidades obrigatórias

- Gerar ou definir número secreto em uma faixa.
- Informar se o palpite é maior ou menor.
- Contar e limitar tentativas.
- Validar palpites e permitir desistência.
- Oferecer nova partida.

## Conhecimentos necessários

- Módulos 01–03: entrada, decisões e repetição.
- Biblioteca random pode ser consultada somente para gerar o número.

## Exemplo de utilização

```text
Palpite: 40
O número secreto é maior.
Palpite: 57
Você acertou em 2 tentativas!
```

O exemplo descreve comportamento esperado, não uma implementação.

## Funcionalidades opcionais

- Níveis de dificuldade.
- Recorde durante a execução.
- Modo para dois jogadores.
